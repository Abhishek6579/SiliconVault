# License status

The repository currently has no root `LICENSE` file and its GitHub metadata does not declare a license.

A software license is a legal grant and must not be selected by automation or inferred from the project's use of open-source dependencies.

Until the copyright holder chooses and adds terms:
- Do not describe SiliconVault as MIT, GPL, Apache-2.0, or licensed under another named license.
- Do not assume permission to redistribute, modify, sublicense, or publish derivative copies.
- Third-party dependencies remain governed by their own licenses; that does not license SiliconVault itself.

Before the first public release, choose the intended licensing model, verify ownership and third-party notices, add the full license text if applicable, and update the README. If the project is proprietary, document that decision instead of adding an open-source license.
