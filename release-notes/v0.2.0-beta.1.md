# SiliconVault v0.2.0-beta.1

SiliconVault enters **Beta**. This release consolidates workspace, editor, search, and update workflow improvements. It is a pre-1.0 release; expect further refinements and report reproducible issues through GitHub.

## What's new

- **Release notes after updates:** after an in-app update and restart, SiliconVault displays the release notes for the installed version.
- **Better workspace search:** filename search supports matching text within names, not only from the beginning.
- **Broader in-document Find:** search is available across text-oriented files, including Markdown and source files.
- **Improved Find navigation:** Find Next and Find Previous behavior and editor focus handling have been refined.
- **Workspace refinements:** tab groups resize more consistently, and the Trash includes an empty-trash action.
- **Editor usability:** zoom behavior and general workspace interactions have received further fixes.

## Packaging and updates

- Windows NSIS (.exe) and MSI (.msi) installers.
- Signed updater artifacts and updater manifest.
- SHA-256 checksums for release installers.

## Beta notice

This is a beta release. Back up important workspace data before upgrading. Workspace backups are not encrypted by SiliconVault; store exported backups securely.
